 ## MemoryAllocator

### kernel — Project Wiki

A small x86_64 (arm64 planned) kernel. Bare metal, no libc, GRUB/multiboot2.
Current state: boot → serial → PMM → VMM → heap → slab. Processes and
syscalls are stubbed.
